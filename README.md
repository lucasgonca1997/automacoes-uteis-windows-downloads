# Automações Úteis para Windows — downloads

## Instalar ou atualizar da versão 1.2.3

1. [Baixe o pacote 1.2.8](https://github.com/lucasgonca1997/automacoes-uteis-windows-downloads/raw/refs/heads/main/AutomacoesUteis-1.2.8.zip).
2. Feche **Automações Úteis** pelo ícone perto do relógio do Windows, escolhendo **Sair**.
3. Extraia o ZIP e copie `AutomacoesUteis.exe` e `Updater.exe` para a pasta onde o aplicativo está instalado, substituindo os arquivos antigos.
4. Abra `AutomacoesUteis.exe`.

As preferências e os autoclickers ficam em `%APPDATA%\AutomacoesUteisWindows\config.ini` e permanecem intactos. A partir da versão 1.2.4, **Buscar atualizações** funciona sem Git e sem login no GitHub. Quem já usa a versão 1.2.4 ou posterior pode instalar a versão atual diretamente pelo botão. Instale o programa em uma pasta onde seu usuário pode substituir arquivos.

A versão 1.2.8 adiciona um teclado numérico temporário às teclas PrtSc/ScrollLock/Pause (7/8/9), Insert/Home/PgUp (4/5/6), Delete/End/PgDn (1/2/3) e seta para cima (0). Toque o Alt direito sozinho para ativar ou desativar. A voz do Windows anuncia o estado; o modo começa desligado. A função de autoclicker continua disponível.

## O que há neste repositório

O ZIP e os dois executáveis são o pacote para Windows 10/11 x64. `version.ini` informa a versão e os hashes SHA-256 usados pelo atualizador para verificar os arquivos baixados. O código de desenvolvimento fica no repositório privado do projeto.
